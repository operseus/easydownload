# EasyDownload

EasyDownload, YouTube və YouTube Music videolarını/mahnılarını ən yüksək keyfiyyətdə saniyələr içində yükləməyə imkan verən pulsuz, reklamsız, yüngül (lightweight) və açıq mənbəli bir masaüstü tətbiqidir.

  <img src="../screenshots/tabs.gif" alt="EasyDownload İnterfeysi" width="700">
</div>

---

## 🚀 Xüsusiyyətlər

* **Ən Yaxşı Keyfiyyət Video Dəstəyi:** Videoları orijinal keyfiyyətini itirmədən 4K həllinə qədər MP4, WebM və ya MKV formatlarında yükləyin.
* **İnkişaf etmiş Səs Çevirici:** YouTube videolarını və ya YouTube Music linklərini tək kliklə yüksək keyfiyyətli MP3 formatına çevirin.
* **Media Məlumatlarını Gömme (Embed Info):** Yüklənən fayllara üz qabığı, sənətçi adı və video başlığı kimi metadatada avtomatik olaraq inteqrasiya edin.
* **İnkişaf etmiş Növbə (Queue) & Tarixçə:** Birdən çox yükləmə tapşırığını növbəyə əlavə edin, arxa planda sırayla yüklənməsini izləyin və tarixçə sekmesindən köhnə yükləmələrinizi asanlıqla idarə edin.
* **Aşağı Resurs İstehlakı:** Arxa planda və ya yükləmə zamanı sisteminizi əsla yormaz, minimum RAM və CPU istifadə edəcək şəkildə optimallaşdırılmışdır.
* **Çoxlu Dil Dəstəyi:** Türk, İngilis, Alman, Fransız, İspan və daha bir çox dil seçimi ilə yerli istifadə.

## 📦 Yükləmə və Quraşdırma

Cari stabil versiyalara və yükləmə fayllarına [GitHub Releases](https://github.com/operseus/easydownload/releases) səhifəmizdən baxa bilərsiniz.

1. **Tövsiyə olunan Quraşdırma:** `EasyDownload-Setup-x.x.x.exe` faylını yükləyin və bir neçə saniyə içində quraşdırın.
2. **Daşına bilən Versiya (Portable):** `EasyDownload-x.x.x-portable.zip` faylını yükləyib bir qovluğa çıxararaq quraşdırma etmədən birbaşa istifadə etməyə başlaya bilərsiniz.

Bu anbar, tətbiqin veb sayt kodlarını, versiyalarını və infrastruktur alətlərini barındırır:
