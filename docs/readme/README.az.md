## 🚀 Xüsusiyyətlər

* **Ən Yaxşı Keyfiyyətli Video Dəstəyi:** Videoları orijinal keyfiyyətini itirmədən 4K qətnaməyə qədər MP4, WebM və ya MKV formatlarında yükləyin.
* **Qabaqcıl Səs Çevirici:** YouTube videolarını və ya YouTube Music linklərini tək kliklə yüksək keyfiyyətli MP3 formatına çevirin.
* **Media Məlumatlarını Göm (Embed Info):** Yüklənmiş fayllara örtük şəkli, rəssam adı və video başlığı kimi metadatları avtomatik olaraq inteqrasiya edin.
* **Qabaqcıl Növbə və Tarixçə:** Növbəyə birdən çox yükləmə tapşırığı əlavə edin, arxa planda ardıcıl olaraq yüklənməsini izləyin və tarixçə nişanından köhnə yükləmələrinizi asanlıqla idarə edin.
* **Düşük Resurs İstehlakı:** Minimum RAM və CPU istifadə etmək üçün optimallaşdırılmışdır, arxa planda və ya yükləmə zamanı sisteminizi heç vaxt yavaşlatmaz.
* **Çox Dilli Dəstək:** İngilis, Türk, Alman, Fransız, İspan və daha bir çox dil variantları ilə lokallaşdırılmış istifadə.

### 🔹 Əla Performans və Yüngüllük
Müasir tətbiqlərdən fərqli olaraq, EasyDownload demək olar ki, heç bir sistem resursu istehlak etmir. Tapşırıq idarəedicisi məlumatları orijinal aydınlığında aşağıdadır:

#### 📊 Boşda Çalışma Modu (`taskmanager-idle.png`)
Tətbiq arxa planda və ya gözləmədə ikən yalnız **~5.2 MB RAM** və %0 CPU istehlak edir.

#### 📥 Yükləmə Əsnasında (`taskmanager-downloading.png`)

## 📦 Yükləmə və Quraşdırma

Tətbiqin ən son sabit versiyalarına, portativ paketlərinə və keçmiş buraxılışlarına birbaşa [**GitHub Releases**](https://github.com/operseus/easydownload/releases) səhifəsindən daxil ola bilərsiniz.

* 📥 **Tövsiyə Edilən Quraşdırma (Sehirbaz):** Ən son sabit versiya olan `EasyDownload-Setup-x.x.x.exe` faylını yükləyin və saniyələr içində quraşdırmanı tamamlayın.
* 🚀 **Portativ Versiya (Portable):** Sisteminizdə heç bir iz buraxmaq istəmirsinizsə, `EasyDownload-x.x.x-portable.zip` arxivini yükləyin, istənilən qovluğa çıxarın və quraşdırma olmadan birbaşa işə salın.

## 🛠 Layihə Quruluşu

Bu anbar tətbiqin veb sayt kodlarını, versiyalarını və infrastruktur alətlərini barındırır:
